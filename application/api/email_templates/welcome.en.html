Your account is ready. Likyly brings together the recommendation engine, the control console and performance tracking: you integrate, you tune, you measure.

Install Likyly with one command

In your site's folder, run the setup wizard:

$ npx @likyly/wizard
 
 It detects your framework
checks that its version is supported, then installs the SDK.
 
 It signs you in
in the browser: your keys come back to the terminal on their own.
 
 It connects your AI assistant
Claude Code, Cursor or VS Code, to the Likyly MCP server, which finishes the integration: catalog, placement, code.
Read the installation guide
Rather integrate yourself? Official SDKs exist for TypeScript, PHP, Python, Java, .NET, Go, Ruby, Rust, Android and Swift, and the REST API is always there. See the SDKs

What Likyly does for you

 
 Recommendations from day one

 Performance you can measure
Impressions, clicks, integration health and model versions, in one place.
